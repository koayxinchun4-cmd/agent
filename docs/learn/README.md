# Learning Hub

Nexus is a **learning-by-building** project. These notes are for the project owner's self-study while developing the app.

## Language policy

- **English-first** for technical concepts, documentation, and terminology.
- **Traditional Chinese** is used only as a short meaning/explanation when a term is unfamiliar.
- Keep the original English term so it can be searched directly in official documentation.
- Do not translate every sentence into Chinese unless a deeper Chinese explanation is requested.

Preferred pattern:

> **Git Blob — 文件内容对象: a Git object that stores file contents.**

## Learning method

Use the concept when it appears in real project work:

```text
Real Nexus task
    ↓
New technical concept
    ↓
Short English explanation
    ↓
Chinese meaning only when needed
    ↓
Implement
    ↓
Test / CI
    ↓
Review what was learned
```

The goal is **understanding, not memorization**.
